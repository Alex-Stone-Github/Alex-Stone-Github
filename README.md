## My Settings

If you would like to install many of many settings, configurations, and macros,
checkout the following: 

1. Clone this repo: `git clone
   https://github.com/Alex-Stone-Github/Alex-Stone-Github`
2. Got into the repo: `cd Alex-Stone-Github`
3. Run the install command, either `make install` to install in a
   terminal only environ or `make install-all` for a full config including
   emacs and alacritty and fonts
